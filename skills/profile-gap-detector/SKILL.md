# 用户画像补全

## 目标

通过对比用户已有的长期记忆和预定义的"画像维度"，发现信息空白，生成一个轻量、自然的问题来补全用户画像。

## 工作文件

- `drift/skills/profile-gap-detector/asked.json`：已问过的问题维度记录，防止重复
- `drift/skills/profile-gap-detector/queue.md`：待问问题队列（每行一个问题）

## 画像维度参考

以下维度供 LLM 判断"用户画像还缺什么"，不是必须全部覆盖的检查表：
- 音乐偏好（喜欢什么类型、有没有特别喜欢的艺人）
- 饮食偏好（口味偏好、忌口、常去的餐厅类型）
- 运动习惯（运动类型、频率、有无健身目标）
- 阅读/观影偏好（书籍类型、电影口味、有无在追的剧）
- 旅行偏好（喜欢的目的地类型、出行方式偏好）
- 创作/表达习惯（是否写东西、用什么工具）
- 社交偏好（线上/线下、社交频率倾向）
- 学习方式偏好（自学 vs 上课、视频 vs 文字）

## 工作流程

1. `read_file` 读取 `asked.json`（如果不存在则为空）。
2. `read_file` 读取 `queue.md`。如果 queue 非空，取第一行作为本次问题；从 queue 中删除该行，写回。
3. 如果 queue 为空：
   a. `recall_memory` 检索用户已有的 profile 和 preference 类记忆。
   b. 对比画像维度，找出 **1 个** 尚未覆盖且最适合当前语境提问的维度。
   c. 检查 `asked.json`：如果该维度已问过，换下一个。
   d. 生成一个自然的问题（像一个朋友随口一问，不要像采访或问卷）。
4. 将选定的维度记录到 `asked.json`。
5. `message_push` 发送问题给用户。
6. `finish_drift(message_result="sent")`。

## 问题生成要求

- **轻量**：一个问题就够了，不要连续追问
- **自然**：像朋友聊天时随口一提，不是问卷调查。用"对了，你..."或"话说..."开头
- **关联语境**：如果 RECENT_CONTEXT.md 显示用户最近在聊相关话题，优先问那个方向
- **避开已有信息**：长期记忆里已经明确的不要问
- **避开敏感领域**：不问收入、政治立场、宗教信仰、健康状况（除非用户主动提及）

## 示例

- ✓ "对了，你平时跑步是户外跑还是在健身房？" （自然，关联运动习惯）
- ✓ "话说你喜欢看什么类型的电影？" （轻量，不压迫）
- ✗ "请问您的音乐偏好是什么？" （太正式，像问卷）
- ✗ "你对以下事项有何看法：1. AI发展 2. 气候变化..." （太宏大）
